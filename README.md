# rushikesh-portfolio-bootstrap

Angular 17 portfolio with Bootstrap 5 — dark professional theme, animations, and sticky bottom navbar.

## Setup
1. Place your assets in `src/assets/`:
   - `Photo.jpg`
   - `Rushikesh_Patil.pdf`

2. Install and run:
```bash
npm install
ng serve
